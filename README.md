# GDO & Mio Capitale — app per il telefono

Questa è solo la "scatola vuota" dell'app per iPhone e Android.

**Qui non ci sono dati.** I dati restano sul Mac di chi usa l'app: vengono esportati in un file
cifrato con una password personale (AES-256) e aperti direttamente sul telefono, senza passare da internet.

Indirizzo dell'app: https://effeelleit.github.io/gdo-mio-capitale/
